# Analysis Methodology

## 1. Displacement Analysis

The displacement dataset was analyzed across 40 snapshots.

The analysis focused on:

- Total internally displaced individuals.
- Total displaced households.
- Changes between consecutive snapshots.
- Percentage change over time.
- Average household size.
- Geographical distribution of displacement.

## 2. Population Returns Analysis

The returns dataset was analyzed across 13 snapshots.

The analysis focused on:

- Total returned individuals.
- Changes in return figures over time.
- Percentage change between snapshots.
- Internal displacement returns.
- Returns from outside Sudan.
- Average household size where data was available.

## 3. Displacement Flow Analysis

Historical origin information was used to distinguish between internal/local displacement and cross-locality displacement in the early available data.

This analysis was limited to the period where the required origin information was available and sufficiently detailed.

## 4. Analytical Approach

Microsoft Excel was used to organize the datasets, calculate indicators, create summary tables, and conduct preliminary exploratory analysis.

Further statistical analysis and interactive visualization will be developed as additional conflict-related datasets become available.

## 5. Limitations

- Snapshot observations do not represent unique individuals across the entire study period.
- Historical origin information is not consistently available across all snapshots.
- Differences in reporting coverage may influence observed changes.
- Documented conflict events may not represent the full number of events that occurred.
