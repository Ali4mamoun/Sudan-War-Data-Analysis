# Sudan War: Data Analysis Project

## Overview

This project explores the humanitarian impact of the ongoing war in Sudan through data analysis, focusing on internal displacement, population returns, and conflict-related events.

The project aims to transform humanitarian data from multiple sources into structured datasets and meaningful insights using data cleaning, statistical analysis, and data visualization techniques.

## Research Objectives

- Analyze displacement trends across Sudan from April 2023 to 2026.
- Examine population return patterns and their changes over time.
- Identify the geographical distribution of displacement and returns.
- Explore the relationship between conflict intensity and population displacement.
- Integrate information from multiple humanitarian data sources.

## Data Sources

The project draws upon information published by:

- **International Organization for Migration (IOM):** Displacement Tracking Matrix (DTM) datasets.
- **Human Rights Watch (HRW):** Reports documenting conflict-related events and human rights violations.
- **Yale Humanitarian Research Lab (Yale HRL):** Research and satellite-based assessments of conflict impacts.

## Tools & Technologies

- Microsoft Excel – Data cleaning, organization, and preliminary analysis.
- Microsoft Power BI – Data visualization and interactive dashboards.
- Data analysis and statistical techniques.

## Project Progress

**Phase 1 – IOM Data Analysis**

- Collection and preparation of displacement datasets.
- Collection and preparation of population return datasets.
- Data cleaning and standardization.
- Exploratory analysis and trend calculations.

**Phase 2 – Conflict Events Analysis**

- Extracting structured conflict-related events from HRW and Yale reports.
- Organizing events by date and geographical location.

**Phase 3 – Data Integration & Analysis**

- Integrating displacement, return, and conflict datasets.
- Exploring relationships between conflict intensity and population movements.

**Phase 4 – Visualization & Reporting**

- Developing interactive Power BI dashboards.
- Documenting findings, limitations, and conclusions.
